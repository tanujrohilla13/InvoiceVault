# Kagaz

Bills, warranties and personal documents in one place, stored in your own Google Drive.

## New in this version
- Share to Kagaz: share an invoice PDF or photo from any app (Amazon, Flipkart, Gmail, WhatsApp, Files) and pick Kagaz.
- Auto-fill from PDFs: store, date, price, product, brand, warranty, serial/IMEI and order number for bills;
  type, number, issue and expiry date for documents (PAN, Aadhaar, insurance policies, licence, etc.).
- New icon.

## Update
1. Upload all files to your GitHub repo (replace the old ones) and commit. Wait 1-2 minutes.
2. On your phone, remove the old Kagaz icon from the home screen.
3. Open your GitHub link in Chrome > menu > Install app (or Add to Home screen).
   Reinstalling is needed once so Android adds Kagaz to the share menu and shows the new icon.
